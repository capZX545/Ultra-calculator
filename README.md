# Ultra Calculator

Two separate programs. They do not import each other. Each folder has its own formula file and its own engine.

- `desktop` — window application (tkinter)
- `web` — browser application (Flask)

Both contain the same named formulas (elementary, hypergeometric, Bessel, gamma/erf, elliptic, zeta, physics, chemistry, biology, engineering), plus:

- engineering keypad
- solve any one unknown in a formula
- add or remove equations and unknowns
- polynomials through degree 6
- numerical methods and first-order ODE
- chemistry equation balancer and molar mass
- periodic table (Z, mass, important isotopes)
- English / Persian / Finnish

See each folder's README for how to start that program.
