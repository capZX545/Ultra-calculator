# Ultra Calculator

Two separate programs. They do not import each other. Each folder has its own formula file and its own engine.

- `desktop` — window application (tkinter)
- `web` — browser application (Flask)

Both contain the same 961 named formulas (encyclopedia subject map, special functions, physics, chemistry, biology, engineering, finance, medicine, music, quantum computing), plus:

- engineering keypad
- solve any one unknown in a formula
- add or remove equations and unknowns
- polynomials through degree 6
- numerical methods and first-order ODE
- chemistry equation balancer and molar mass
- periodic table (Z, mass, important isotopes)
- English / Persian / Finnish
- Sources tab: Equation Encyclopedia, MathWorld, NIST DLMF, CRC/CODATA, PhET, arXiv, Wolfram Functions

See each folder's README for how to start that program.

These sites are used as a subject map and public constants, not as a dumped copy of their full libraries. CRC is a paid book; arXiv is papers, not a formula table. Named equations still solve for a missing variable.
